Use the bundled examples to explore each workflow with reproducible media.

## Using this feature {#usage}

| File in examples/ | Practice |
| --- | --- |
| FirstLight.sframe | Play the procedural title/light scene and original audio |
| CutStudy.sframe | Trim linked clips and compare ripple vs keep-gap |
| GraphStudy.sframe | Change the desaturation parameter and animate it |
| LayerGraphStudy.sframe | Trace warm/cool branches and their animated blend |
| MotionStudy.sframe | Change a widget anchor and title size |
| ClipStudy.sframe | Edit a nested timeline and Apply to Container |
| GradingStudy.sframe | Bypass each correction and compare scopes |
| DspStudy.sframe / ParallelEQ.json | Inspect two EQ branches and stereo sum |
| MixerStudy.sframe | Follow bus/send routing and effect tails |
| PrecisionStudy.sframe | Export a half-float frame with HDR values |
| TransitionStudy.sframe | Adjust overlap and transition duration |
| MaskStudy.sframe / VfxStudy.sframe | Inspect mask guides and effect processing |

Save a copy before changing an example. Some scenes fade in and out: seek to around four seconds to see a representative image. The supplied soundtrack is generated for demonstration; keep its relative file beside the projects when moving the example folder.

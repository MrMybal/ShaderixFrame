Explorez chaque fonction avec les exemples et médias reproductibles fournis.

## Utilisation {#usage}

| Fichier dans examples/ | Exercice |
| --- | --- |
| FirstLight.sframe | Lire titre/lumière procédurale et audio original |
| CutStudy.sframe | Rogner des clips liés, comparer ripple et vide conservé |
| GraphStudy.sframe | Changer et animer la désaturation |
| LayerGraphStudy.sframe | Suivre branches chaudes/froides et leur mélange animé |
| MotionStudy.sframe | Changer ancre de widget et taille de titre |
| ClipStudy.sframe | Modifier la timeline imbriquée puis appliquer |
| GradingStudy.sframe | Désactiver chaque correction et comparer les scopes |
| DspStudy.sframe / ParallelEQ.json | Inspecter les branches EQ et la somme stéréo |
| MixerStudy.sframe | Suivre bus/envois et fins d’effets |
| PrecisionStudy.sframe | Exporter une image flottante avec valeurs HDR |
| TransitionStudy.sframe | Ajuster chevauchement et durée |
| MaskStudy.sframe / VfxStudy.sframe | Inspecter guides de masque et effets |

Enregistrez une copie avant de modifier un exemple. Certaines scènes ont des fondus : placez la tête vers quatre secondes pour une image représentative. La bande-son fournie est générée pour la démonstration ; conservez son fichier relatif avec les projets si vous déplacez le dossier.

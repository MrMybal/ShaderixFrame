Arrange the interface, detach panels and choose a theme or language.

## Using this feature {#usage}

| Workspace | Shortcut | Use |
| --- | --- | --- |
| Edit | F1 | Media, preview and large timeline |
| Effects | F2 | Layer, track and shader graphs, HLSL |
| Motion | F3 | Widget canvas and animation curves |
| Color Grading | F4 | Corrections, comparison and scopes |
| Audio | F5 | Mixer, channel devices and DSP graph |
| Deliver | F6 | Export queue, plugins and MCP |

Close a panel with its tab cross; reopen it from View. Drag tab headers to rearrange docking, or outside the main window to make a native window on another monitor. Each workspace remembers panels, sizes and arrangement. View > Reset This Workspace restores a usable layout. The CyDoc manual opens in a separate browser window beside any workspace.

View > Appearance offers the CyUI themes, compact/comfortable density and English/French interface. English is the default. Ctrl+Shift+P opens the command palette; type a command or panel name and press Enter. Personal appearance, keyboard and workspace preferences are stored beside the executable; they are not project content.

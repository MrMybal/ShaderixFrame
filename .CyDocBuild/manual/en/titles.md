Add readable text, lower thirds and timed subtitle cues.

## Using this feature {#usage}

Add Title creates a text clip on an available title track. Properties edits multiline text, installed Windows font, bold/italic, alignment, size, color, outline, shadow and background box. Size and supported style values can be animated. The context menu supplies classic, yellow subtitle, black box, cinema and neon styles; typewriter reveals letters over time.

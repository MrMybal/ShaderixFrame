Raccourcis initiaux, actions selon le contexte et personnalisation.

## Utilisation {#usage}

| Action | Raccourci initial |
| --- | --- |
| Manuel / palette | Ctrl+F1 / Ctrl+Maj+P |
| Espaces | F1 montage, F2 effets, F3 motion, F4 couleur, F5 audio, F6 livraison |
| Nouveau / ouvrir / enregistrer / importer | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+I |
| Annuler / rétablir | Ctrl+Z / Ctrl+Y |
| Copier / couper / coller / dupliquer | Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D |
| Coller les attributs | Ctrl+Alt+V |
| Tout choisir / désélectionner / chercher | Ctrl+A / Échap / Ctrl+F |
| Couper / supprimer / supprimer ripple | S / Suppr / Maj+Suppr |
| Rogner début / fin en ripple | Q / W ; Alt garde le vide |
| Décaler des clips | Alt+Gauche/Droite ; Maj pour dix images |
| Lecture / autour de la tête | Espace / Maj+Espace |
| Navette arrière / arrêt / avant | J / K / Maj+L |
| Boucle / entrée-sortie de zone | L / I / O |
| Image / seconde / coupe | Gauche/Droite / Maj+Gauche/Droite / Haut/Bas |
| Début / fin de séquence | Début / Fin |
| Repère / groupe de pistes | M / Ctrl+G |
| Vitesse / arrêt image / activer | Ctrl+R / Maj+F / Maj+E |
| Sélection avant / arrière | A / Alt+A |
| Correspondance source / cadrer sélection | F / Z |

Outils : V Sélection, B Lame, Y Slip, N Roll, R Étirement, U Glissement, H Main. Timeline : Ctrl+molette zoome, Maj+molette déplace le temps, Alt+molette change les hauteurs, milieu-glisser déplace. Graphes : molette zoome, milieu déplace, clic droit ouvre les actions. Composition : Ctrl+0 cadre et Ctrl+1 passe à 100 %.

View > Keyboard Shortcuts permet de réaffecter les actions listées. Les conflits sont affichés et keymap.json les conserve près de l’exécutable. Toutes les commandes fixes ou locales ne sont pas réaffectables. F1 reste l’espace Edit ; l’aide utilise Ctrl+F1. Dans CyDoc, Ctrl+K recherche dans le manuel ; la fenêtre du navigateur possède son propre contexte clavier.

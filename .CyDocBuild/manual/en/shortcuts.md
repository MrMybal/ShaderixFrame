Default bindings, context-sensitive actions and customization.

## Using this feature {#usage}

| Action | Default |
| --- | --- |
| Manual / command palette | Ctrl+F1 / Ctrl+Shift+P |
| Workspaces | F1 Edit, F2 Effects, F3 Motion, F4 Color, F5 Audio, F6 Deliver |
| New / open / save / import | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+I |
| Undo / redo | Ctrl+Z / Ctrl+Y |
| Copy / cut / paste / duplicate | Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D |
| Paste attributes | Ctrl+Alt+V |
| Select all / deselect / find | Ctrl+A / Escape / Ctrl+F |
| Split / delete / ripple delete | S / Delete / Shift+Delete |
| Head / tail ripple trim | Q / W; Alt keeps gap |
| Nudge clips | Alt+Left/Right; Shift for ten frames |
| Play / around playhead | Space / Shift+Space |
| Shuttle backward / stop / forward | J / K / Shift+L |
| Loop / work area in/out | L / I / O |
| Step / second / edit point | Left/Right / Shift+Left/Right / Up/Down |
| Sequence start / end | Home / End |
| Marker / group tracks | M / Ctrl+G |
| Clip speed / freeze / enable | Ctrl+R / Shift+F / Shift+E |
| Select forward / backward | A / Alt+A |
| Match frame / fit selection | F / Z |

Tools: V Select, B Blade, Y Slip, N Roll, R Rate Stretch, U Slide, H Hand. Timeline Ctrl+wheel zooms, Shift+wheel pans time, Alt+wheel changes track heights, middle-drag pans. Graph wheel zooms, middle-drag pans, right-click opens actions. Composition Ctrl+0 fits and Ctrl+1 sets 100%.

Open View > Keyboard Shortcuts to rebind the actions it lists. Conflicts are shown and bindings are saved in keymap.json beside the executable. Fixed application shortcuts and panel-specific controls are not all rebindable. F1 remains the Edit workspace; help uses Ctrl+F1. In CyDoc Ctrl+K searches the manual; its browser window has a separate keyboard context from the editor.

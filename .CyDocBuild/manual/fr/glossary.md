Distinguez timelines, graphes et cibles de traitement.

## Utilisation {#usage}

| Terme | Signification |
| --- | --- |
| Source | Fichier média et portion qu’on y choisit |
| Clip | Contenu placé avec début, durée, lecture source, effets et clés |
| Piste / calque | Ligne temporelle produisant surface image ou signal audio |
| Conteneur | Clip contenant une séquence locale indépendante |
| Effet de clip | Traitement d’un seul clip avant la composition suivante |
| Track Graph | Traitement de la surface d’une piste vidéo |
| Layer Graph | Composition et mélange des surfaces de pistes |
| Shader Graph | Graphe typé compilé en shader de traitement d’image |
| DSP Graph | Topologie audio stéréo compilée par le plan CyDAW |
| Bus / envoi | Somme audio partagée / connexion supplémentaire |
| Clé | Valeur à un instant, interpolée pour l’animation |
| Zone de travail | Intervalle pour boucle, cache ou export |
| Proxy | Copie légère de montage ; original utilisé à l’export |
| RGBA16F | Précision intermédiaire image à quatre canaux demi-flottants |
| LUT | Table de correspondance des couleurs |
| LUFS / dBTP | Sonie du programme / crête vraie |
| Worker | Processus séparé hébergeant un plugin compatible |
